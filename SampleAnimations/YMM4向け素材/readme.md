# YMM4向け素材

YMM4でキャラクターとしてお使いいただける素材です。

キャラクター素材一式は、YMM4で「動く立ち絵」として使用できるファイル構成になっています。
ZIPファイルを解凍後、動く立ち絵の素材の場所として選択してください。

## 利用規約

本素材は、以下の範囲でご利用いただけます。

|利用範囲                |利用可否| |
|------------------------|--------|-|
|非商用利用              |○可能  | |
|商用利用                |△条件付き可能|動画への埋め込みのみ可能|
|アフィリエイトでの利用  |×禁止  | |
|動画配信サイトでの収益化|△条件付き可能|企業に属していない個人に限り可能|
|Twitter等のSNSでの利用  |△条件付き可能|個人のアイコンとしてのみ利用可能|
|素材の加工              |○可能  |ただし別キャラクターへの改変は禁止|
|素材の再配布            |×禁止  |加工の有無にかかわらず禁止|

### クレジット表記

素材の加工を行わない場合は不要です。
素材を加工してご利用される場合は、「MicroSignのYMM4向け素材の加工素材」である事を明示して下さい。

### 免責

本素材の利用によって生じたいかなる損害についても、配布者は一切の責任を負いません。
