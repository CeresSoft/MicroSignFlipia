# 季節アニメーション

MicroSignで再生できる季節のアニメーションです。

変換済みのbinファイルですので、MicroSDカードに書き込むことでそのままお使いいただけます。
書き込む際、ファイル名を `MicroSignImage.bin` に変更してください。

## 利用規約

MicroSignでの再生用途であれば、個人・企業・商用・非商用を問わず、無料でご利用頂けます。

### 禁止事項

- 公序良俗に反する利用
- アニメーションデータの改変
- アニメーションデータの再配布

### 免責

本アニメーションの利用によって生じたいかなる損害についても、配布者は一切の責任を負いません。
